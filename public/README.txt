MJ JOKER — pacote visual para Render

1. No GitHub, abra o repositório mj-joker.
2. Substitua o index.html antigo por este index.html.
3. Coloque render.yaml na raiz do repositório.
4. Faça Commit changes.
5. No Render, abra o serviço mj-joker e aguarde o deploy automático.

Este é um protótipo de quiz gratuito. Não inclui depósitos, apostas, pagamentos, prémios em dinheiro, registo real de contas ou armazenamento central de utilizadores.
